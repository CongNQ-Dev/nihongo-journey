# nihongo-journey

Khoá tự học tiếng Nhật từ số 0 đến JLPT N2, rồi N1 (đủ 4 kỹ năng nghe – nói – đọc – viết), dùng Minna no Nihongo làm trục chính. Bài học viết bằng tiếng Việt.

Mở `index.html` bằng Chrome hoặc Safari: mục lục 11 bài bảng chữ cái (hiragana 0001–0007, katakana 0008–0011). `flashcards.html` là trang ôn hằng ngày.

Bài 0002–0011, `assets/cards.js`, hai bảng tra cứu và `index.html` được sinh từ `tools/kana_data.py` bằng `python3 -I tools/build.py`. Ảnh thẻ được tìm bằng `tools/fetch_images.py`. Mục tiêu và ghi chú giảng dạy nằm ở `MISSION.md` và `NOTES.md`.

Repo này không chứa nội dung sách Minna no Nihongo (có bản quyền). Bài học chỉ đi theo thứ tự của sách.
