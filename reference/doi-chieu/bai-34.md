# Đối chiếu Minna bài 34: Làm theo, làm sau khi, làm mà không

Cách dùng: mở sách Minna bài này, so từng dòng. Ghi ✓ nếu khớp, hoặc ghi cách sửa vào cột cuối.
Nghĩa tiếng Anh tra tự động nên có thể lệch nghĩa hoặc để trống (từ ghép, câu giao tiếp, tên riêng).

## Mẫu câu của bài (khoá đang dạy)

- V1-る／V1-た／N の とおりに、V2 — làm V2 đúng như V1
- V1-た／N の あとで、V2 — sau khi V1 thì V2
- V1-て／V1-ないで V2 — làm V2 theo kiểu V1 (vừa, bằng cách) / làm V2 mà không V1
- V-ないで、V2 (thay vì) — thay vì V1 thì V2
